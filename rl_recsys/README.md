# RL-дообучение GPT-2 для музыкальных рекомендаций

Исследование на Yambda: предсказание следующего трека, модель пользовательского
отклика и RL-оптимизация доли прослушивания, времени и продолжения сессии.
[Отчёт](FINAL_REPORT.md) содержит постановку, методы, результаты и ограничения.

Результаты на 845 пользователях, не участвовавших в обучении. RL-строки —
среднее двух запусков от одной базовой GPT-2; награда — прогноз RM.

| Метод | NDCG@10 | Recall@10 | Доля (RM) | Время, с (RM) |
| --- | --- | --- | --- | --- |
| GPT-2 без RL | 0.02363 | 0.03881 | 0.72748 | 142.72212 |
| RL: доля, β=0,2 | 0.02415 | 0.03918 | 0.72853 | 141.63445 |
| RL: доля, β=0,5 | 0.02393 | 0.03932 | 0.72800 | 142.13253 |
| RL: время, β=0,2 | 0.02242 | 0.03713 | 0.72494 | 150.57945 |
| RL: смешанная награда, H=1 | 0.02370 | 0.03915 | 0.72709 | 144.71031 |
| RL: смешанная награда, H=5 | 0.02320 | 0.03801 | 0.72714 | 145.88190 |
| Переранжирование: доля, β=0,2 | 0.02434 | 0.04109 | 0.73072 | 141.66801 |

Прирост NDCG у RL с β=0,2 не подтверждается доверительными интервалами.
Слабый KL увеличивает награду ценой потери точности; оптимизация времени
сдвигает рекомендации к более длинным трекам. При оптимизации доли
переранжирование с β=0,2 даёт более высокие точечные оценки награды и NDCG,
чем RL с тем же коэффициентом.

## Запуск

Python 3.10; команды из родительского каталога `rl_recsys`:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r rl_recsys/requirements-final.txt
python -m rl_recsys.final_bundle --verify
python -m pytest -q rl_recsys/tests
python -m rl_recsys.refined_verify
python -m rl_recsys.refined_recommend --model fraction_kl_seed42 --split extra --example-index 0
```

Обучение RM/RL и запуск базовой модели на GPU — в [разделе 8 отчёта](FINAL_REPORT.md#8-запуск).

## Файлы

- `refined_data.py` — временные контексты и признаки прошлых откликов.
- `refined_models.py` — GPT-2, RM, функции награды и переход состояния.
- `refined_experiment.py` — обучение, выбор весов и оценка.
- `refined_recommend.py` — выдача рекомендаций по тестовому контексту.
- `refined_report.py` — таблицы, графики и отчёт.
- `artifacts/refined` — веса RL и RM; `reports/refined` — численные результаты.
- `COLAB.ipynb` — обучение базовой модели на GPU с `best.pt` и `temp.pt`.
