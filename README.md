# Автоматический отбор признаков для рекомендаций KION

Сравнение CatBoost на ручных признаках с автоматическим дополнением и заменой
агрегатов. Для отбора используется корреляция признаков с ошибками моделей,
обученных на предыдущих неделях. Проверка проведена на трёх тестовых неделях
с двумя значениями random seed.

## Результаты

| Модель | NDCG@10 | Recall@10 |
|---|---:|---:|
| CatBoost, 46 ручных признаков | 0,14810 | 0,21889 |
| Ручные признаки + автоотбор | 0,14980 | 0,22207 |
| Ручные признаки + случайные агрегаты | 0,14836 | 0,22174 |
| Замена ручных агрегатов | 0,14594 | 0,21825 |
| Популярность за 7 дней | 0,13890 | 0,21600 |

Значения усреднены по двум seed внутри недели, затем по трём неделям.
Автоотбор увеличил средний NDCG@10 примерно на 1,15%. Парный 95%-интервал
прироста выше нуля на двух неделях из трёх. Устойчивая замена ручных агрегатов
без потери качества не получилась.

Подробные результаты и ограничения — в [отчёте](REPORT.md).
[Пилотный эксперимент](PILOT_REPORT.md) содержит исходное сравнение на одной неделе.

## Данные и метод

Используется [KION](https://github.com/irsafilo/KION_DATASET): случайная выборка
50 000 пользователей, все 285 343 доступные записи по ним. Исходный архив
`data_original.zip` закреплён на коммите
`f69775be31fa5779907cf0a92ddedb70037fb5ae`. Контрольные суммы сохраняются
в `data/raw/manifest.json`.

Для каждого пользователя формируется до 200 кандидатов: общая и недавняя
популярность, фильмы из предпочитаемых жанров и соседи по совместным просмотрам.
Списки объединяются через Reciprocal Rank Fusion. Признаки и кандидаты
строятся по записям с `last_watch_dt` строго раньше начала целевой недели.

Ручной набор включает активность и популярность за 7/30 дней и всё прошлое,
давность просмотров, предпочтения по жанрам, странам, актёрам и режиссёрам,
метаданные и оценки генератора. Автоматический набор — 144 комбинации временных
окон, экспоненциального затухания и агрегатов. Число добавляемых признаков
(12 или 24), глубина и число деревьев выбираются по validation NDCG@10.

На обучающую неделю выбираются 3 000 пользователей. Сохраняются все
положительные кандидаты и до 30 случайных отрицательных с весами,
компенсирующими сэмплирование. Истории пользователей остаются полными.
Validation и test оцениваются на полных списках кандидатов; пропущенные
генератором целевые фильмы остаются в знаменателях NDCG@10 и Recall@10.

## Запуск

Python 3.10, CPU. Эксперименты выполнялись на macOS ARM64 с 8 GiB RAM
и четырьмя потоками CatBoost. Команды выполняются из корня репозитория.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.download
python -m unittest discover -s tests -v
python -m src.pipeline all
python -m src.robustness all
python -m src.robust_report
```

Для воспроизведения пилотного автоотбора и сборки обоих отчётов:

```bash
python -m src.auto_pipeline all
python -m src.diagnostics
python -m src.final_report
```

У пайплайнов доступны отдельные команды `prepare`, `fit` и `evaluate`.
`evaluate` использует сохранённые модели без переобучения. Параметры находятся
в [config.json](config.json), [auto_config.json](auto_config.json)
и [robust_config.json](robust_config.json). Для изменённой конфигурации
используйте отдельную папку результатов, например:

```bash
python -m src.robustness all --config my_config.json --output artifacts/my_run
```

Сборщики Markdown-отчётов используют стандартные папки результатов и описывают
конфигурацию этого исследования. При другом эксперименте текст отчёта
нужно обновить. На разных платформах возможны небольшие численные различия.

| `src/features.py`, `src/pipeline.py` | Ручные признаки и исходный baseline |

Данные, кэши и веса моделей исключены из Git. После запуска они сохраняются
в `data/` и `artifacts/`. Модели проверки на трёх неделях —
в `artifacts/robustness/fold_*/`.

Рекомендации исходного baseline для пользователя с историей до 16 августа 2021:

```bash
python -m src.recommend --user-id USER_ID --save recommendations.csv
```

Вместо `USER_ID` подставьте ID из `artifacts/baseline/sample_users.csv`.
Команда использует пилотную модель. Примеры с названиями фильмов находятся
в [reports/03_examples.md](reports/03_examples.md).

## Ограничения

KION содержит агрегированные пары user–item с датой последнего просмотра,
а не полный журнал событий. Эксперимент предсказывает записи следующей недели;
восстановить первые и повторные просмотры или оценить CTR по этим данным нельзя.
Метаданные считаются постоянными. Метрики рассчитаны для пользователей
с историей и хотя бы одной целевой записью; cold-start отдельно не моделируется.

Периоды ранее использовались в пилоте, поэтому проверка не является новым
слепым внешним тестом. Пользователи и обучающие недели пересекаются:
шесть запусков нельзя считать независимыми. Доверительные интервалы
рассчитаны отдельно для каждой недели.
